# `mimo` — models

`-m <provider/model>` — the provider is embedded in the id. Regenerate with `mimo models`.

| Model id | Notes |
|---|---|
| `mimo/mimo-auto` | auto selection |
| `xiaomi/mimo-v2.5-pro-ultraspeed` | fastest |
| `xiaomi/mimo-v2.5` | default |
| `xiaomi/mimo-v2.5-pro` | strongest |
